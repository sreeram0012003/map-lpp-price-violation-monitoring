# MAP/LPP Violation Dashboard

## Purpose
This Power BI dashboard analyzes product pricing violations across online marketplaces.

## Dashboard Features
- Total price violations
- Warning 1 and Warning 2 counts
- Violations by marketplace
- Violations by product category
- Top sellers by violation count
- Detailed violation records

## Data Source
MySQL database: `data_analysis`

Main table: `violation_table`

## Tools Used
- Microsoft Power BI
- MySQL
- DAX

## Key Metrics
- Total Violations
- Warning 1 - Email
- Warning 2 - Email

## How to Open
1. Download `map_project_violation_analysis.pbix`.
2. Open it using Power BI Desktop.
3. Configure the database connection if required.
4. Refresh the data to view updated results.

## Note
The dashboard displays data available in the project's database. Actual real-time updates depend on the data refresh configuration.

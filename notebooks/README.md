# MAP/LPP Project Notebooks

## Purpose
This folder contains Jupyter notebooks used for data exploration, analysis, and web scraping.

## Notebooks

### 1. data_tables.ipynb
- Explore project datasets.
- Check table structures and column names.
- Inspect and understand the data.
- Prepare data for further analysis.

### 2. web_scrapping_2.ipynb
- Explore product price data from web pages.
- Collect product information using web scraping.
- Inspect the collected data.
- Prepare scraped data for price monitoring.

## Tools and Libraries
- Python
- Jupyter Notebook
- Pandas
- NumPy
- BeautifulSoup
- Requests

## Workflow
1. Load or collect data.
2. Inspect the dataset.
3. Clean and prepare the data.
4. Use the prepared data in the MAP/LPP monitoring workflow.

## Important
Follow the website's terms and conditions when collecting product data. Do not store passwords or other sensitive information in notebooks.

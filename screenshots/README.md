## Project Workflow

### 1. Data Collection Using Python
- Collected product pricing data for MAP/LPP monitoring.
- Used Python and web scraping to collect product information.
- Stored the collected data for further processing.

### 2. Data Cleaning and Processing
- Loaded datasets into Jupyter Notebook using Pandas.
- Checked missing values and duplicate records.
- Cleaned and transformed the data.
- Prepared the final dataset for analysis.

### 3. Load Data into MySQL
- Connected Python to MySQL.
- Loaded the processed datasets into the `data_analysis` database.
- Organized data into tables for further analysis.

### 4. SQL Analysis
- Queried product pricing and seller information.
- Identified potential MAP/LPP pricing violations.
- Analyzed violations by seller, marketplace, and category.

### 5. Violation Detection
- Compared advertised prices with applicable promotional prices.
- Identified records that met the project's violation rules.
- Assigned warning actions based on violation counts.

### 6. Email Automation
- Generated violation notices using Python.
- Created Word documents containing violation details.
- Sent email notifications with the generated notices attached.

### 7. Power BI Dashboard
- Connected Power BI to MySQL.
- Built an interactive dashboard to analyze pricing violations.
- Visualized violations by marketplace, category, seller, and action.
- Added filters for marketplace, category, season, region, and violation action.

## Technologies Used

- **Python:** Data collection, cleaning, and processing
- **Jupyter Notebook:** Data exploration and analysis
- **Pandas:** Data manipulation
- **MySQL:** Database storage and SQL analysis
- **Power BI:** Interactive dashboards and visualization
- **BeautifulSoup / Requests:** Web scraping, where applicable
- **Python SMTP:** Email automation
- **python-docx:** Word violation notices

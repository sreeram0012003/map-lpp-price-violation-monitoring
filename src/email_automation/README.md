# MAP/LPP Email Automation

## Purpose

Automatically generate price violation notices and send email
notifications to sellers.

## Features

- Generates Word violation notices.
- Includes SKU and seller details.
- Includes advertised and promotional prices.
- Attaches the generated notice to the email.
- Sends notifications using Gmail SMTP.

## Requirements

- Python
- python-docx

## Installation

```bash
pip install python-docx
```
